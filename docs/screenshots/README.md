# 截图

README 的顶部预留了截图位置，这里是图要放的地方。

## 需要 4 张

命名固定，README 里取消注释即可生效：

| 文件名 | 拍什么 | 为什么选它 |
|---|---|---|
| `01-home.png` | **首页状态栏**（四块：日期+精力+连续天数 / 今天练什么 / AI 昨天观察到 / 两个入口） | 一眼看出这是个什么产品 |
| `02-debate.png` | **辩论房进行中**（用户一句、AI 一句，能看到流式对话） | 核心交互 |
| `03-review.png` | **复盘卡片**（做得好 / 值得注意 / 如果再来一次 + 最多两条观察） | **最有说服力的一张**——产品理念全在这张卡上 |
| `04-wall.png` | **弱点墙**（四区便签：AI 候选 / 观察中 / 改善中 / 暂存） | 展示完整闭环 |

## 怎么截

1. 浏览器打开 `https://duijing.xyz`（未备案，国内直连会被 SNI 重置，需要梯子）
2. Windows：`Win + Shift + S` 框选，自动存到剪贴板 → 粘进画图另存为 PNG
3. **把窗口拉到一个合适的宽度**（建议 1280 或 1440），太窄看不出布局、太宽字会小

## 注意

- **不要截到真实用户的隐私内容**。生产库里有 4 个真实用户的辩论记录——
  截图前确认画面里没有别人的弱点标签、昵称、原文
- 最稳的做法：**本地跑一份 `AI_PROVIDER=mock`**，注册一个新账号，
  自己走一遍流程再截。数据是假的，随便截
